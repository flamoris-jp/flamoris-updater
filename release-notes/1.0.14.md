# FLAMORIS Updater 1.0.14

Fixes executable cleanup after successful managed updates (#50). All selected stopped containers are verified and removed before image cleanup. Current/retained images and images referenced by other containers stay in place; missing containers/images are reconciled from observed state. No force or prune is used.

Cleanup no longer constructs an installation runtime or reads unrelated private DB/bootstrap inputs. Packages containing active configuration inputs remain protected. Guard failures and per-target decisions are recorded without command output or credentials. Explicit previous deletion can reconcile partial cleanup, and successful reconciliation clears related successful Jobs' cleanup_pending flags atomically with retained pointers. Failed/unknown update Jobs still block deletion and are never replayed.

Self-update compatibility: 1.0.3 through 1.0.13. Existing v1 journals, bootstrap supervisor, settings, DBs, generated media and external runtimes remain compatible. Fixture/CI verification and real-host acceptance are separate.
