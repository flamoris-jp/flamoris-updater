# FLAMORIS Updater 1.0.7

Dockerの従来方式とcontainerd方式で、カタログのイメージIDと実機の起動用IDが異なる場合に対応します。読み込まれたイメージ内部のConfigをSHA-256で照合してから、実際の起動用IDをインストール記録に保存します。配布物、CPU、アプリ名・版、Generation Controller構成の検証は維持します。

イメージ照合で停止したDBなしのDocker新規インストールには、管理者向けの限定したオフライン復旧手順を追加しました。既存の設定・配布物・配置・ジョブ記録を確認し、コンテナ作成前の状態だけを再開します。DB初期化やコンテナ作成に進んだジョブは対象外です。

Updater 1.0.3、1.0.4、1.0.5、1.0.6からの自己更新カタログを含みます。既存アプリの更新互換性や、GPU・外部プロバイダーの動作を保証するものではありません。[復旧手順](../docs/DOCKER_IMAGE_STORE.md)を参照してください。
