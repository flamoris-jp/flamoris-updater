# FLAMORIS Updater 1.0.8

管理画面のヘッダーを固定し、実際のサーバー名・稼働版・接続状態を常時表示します。サーバーごとの配色はブラウザーで選択・保存できます。

自己更新中などにHTMLや壊れたJSONが返っても、JSON解析例外をそのまま表示せず、HTTP状態と対象APIを案内します。読み取り通信は回復後に接続表示を戻します。操作の失敗は確認するまで残り、インストール・更新・初回設定操作は自動再送しません。稼働版が変わったら画面も読み直します。

初回設定ボタンを離し、起動中・起動処理完了・動作確認結果を表示します。自動生成の設定項目には「空欄の場合は自動生成します」と表示します。既存カタログの生成指定を使い、公開済みアプリの配布内容は変更しません。

カタログ登録・解除による参照先の切り替え方法と、Updater本体の実際の配置を画面に表示します。既存の設定・アプリ・実行履歴・元のsupervisor配置は保持します。Updater 1.0.3から1.0.7の自己更新に対応します。

GitHub接続設定の画面は[Issue #32](https://github.com/flamoris-jp/flamoris-updater/issues/32)で別途対応します。ログ出力先の変更、Updater認証・バックアップ機能、アプリのDB移行処理は追加しません。GPU・外部AIプロバイダーの動作確認は別工程です。
