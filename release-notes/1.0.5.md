# FLAMORIS Updater v1.0.5

PrivateなGitHub Releaseのカタログと配布物を、元のリポジトリから取得できるようにしました。

- 既存のGitHub CLI認証、または実行環境のGH_TOKEN / GITHUB_TOKENを使用します。Updater独自のログイン、トークン入力画面、認証情報の保存機能はありません。
- 通常の公開ダウンロードは匿名のままです。GitHubが最初に404を返した場合だけ、対象リポジトリのRelease APIへアクセスします。
- GitHubトークンはapi.github.comにだけ送信します。ファイル転送先へのリダイレクトでは認証情報を除外し、サイズ・SHA-256・不変な配布定義の確認を維持します。
- 元の設定・データ・履歴を引き継ぎ、1.0.3 / 1.0.4からの自己更新に対応します。既存supervisorは公開された新版の取得に使えます。

Linux/systemd・Python 3.12、amd64/arm64対応。Private配布物の取得には対象リポジトリの読み取り権限と、managerが利用できるGitHub認証が必要です。[設定方法](https://github.com/flamoris-jp/flamoris-updater/blob/v1.0.5/docs/GITHUB_RELEASES.md)を参照してください。実機設定・更新はこの公開とは別です。
