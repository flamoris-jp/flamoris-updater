# FLAMORIS Updater v1.0.2

GitHub ReleasesのURLを、初回カタログ・更新カタログ・アプリ配布物・Updater本体の取得に使えるようになりました。
HTTPSのリダイレクトを最大5回まで確認し、GitHub Releaseから公式配布ホストへの移動を限定して許可します。

- Public downloads accept checked same-origin HTTPS redirects and only the exact
  GitHub Release download to `release-assets.githubusercontent.com` exception.
  URL credentials, HTTP downgrade, unexpected hosts/ports, path traversal,
  excessive redirects and oversized responses stop before unsafe requests.
- Ambient authorization, proxy authorization and cookies are not forwarded.
  System TLS trust, SHA-256, indexed native-bundle verification and immutable
  catalog/recipe bindings remain enforced. Advanced signed/coordinator/registry
  downloads retain their default no-redirect policy.
- The separate application-candidate packager assembles all six initial apps on
  amd64/arm64 into a verified catalog, payload map and checksums. This release
  does not itself publish application payloads or configure their catalog.
- Existing 1.0.1 installations need explicit administrator maintenance of Web,
  manager **and the pinned supervisor**. Ordinary self-update replaces only the
  first two; it cannot repair the old supervisor's downloader. Inspect active
  Jobs, protected journals and service bindings before maintenance; preserve
  authentication, settings, history and the original runtime. Do not run initial
  bootstrap over existing state. No database or journal schema migration occurs.

Linux amd64/arm64 indexed bundles, wheel/source, unchanged Core SDK 1.0.0,
schemas, instructions and SHA-256 sums are included. Python 3.12/systemd and
external HTTPS access are required. Real-host update, browser/MCP acceptance and
application installation remain separate from automated CI. No automatic failure
recovery, backup/restore, client PKI or infrastructure provisioning is added.
