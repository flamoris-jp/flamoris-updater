# FLAMORIS Updater v1.0.3

rootで動く更新処理が、検証済みの本体へPythonのbytecodeキャッシュを追加しないよう、Nativeバンドルの起動処理を修正しました。
1.0.2のGitHub Releaseリダイレクト対応も含みます。

- Every indexed bundle launcher disables Python bytecode generation before
  importing bundle modules. Root can bypass ordinary read-only file permissions;
  mode 0555 alone does not prevent it from adding unindexed cache files.
- Native-bundle verification checks the complete index again after executing all
  entrypoints and the identity probe. Both CI and publication exercise the actual
  packaged bundle as an ordinary runner user and as root on amd64/arm64.
- Existing 1.0.1 installations still require explicit administrator maintenance
  of Web, manager and the pinned supervisor. Inspect protected Jobs/journals and
  bindings; preserve authentication, settings, history and the original runtime.
  Initial bootstrap must not run over existing state. No schema migration occurs.

Linux amd64/arm64 indexed bundles, wheel/source, unchanged Core SDK 1.0.0,
schemas, instructions and SHA-256 sums are included. Python 3.12/systemd and
external HTTPS access are required. Published 1.0.1/1.0.2 assets are unchanged.
Real-host rollout, application publication, Web setup and external MCP acceptance
remain separate from CI. No automatic rollback, backup/restore or PKI is added.
