# FLAMORIS Updater 1.0.11

Configure an existing YuE2 media directory on an already managed Generation
installation, through Web, MCP or CLI. The operator choice is recorded separately
from release recipes, used for the dedicated media bind/environment override,
and retained by subsequent compatible updates. No host-specific default is
introduced. Existing private mounts, settings bytes, models, media, permissions
and GPU runtimes are preserved.

The configuration operation is a durable Job, verifies runtime access and idle
status, restarts only Generation, and retains the previous container. Empty
configuration disables publication without deleting media. Failed or interrupted
Jobs require investigation and are not replayed. Controller 1.0.1 or newer and
an authenticated internal Controller connection are required. Do not submit
generation during the configuration Job.

Self-update is compatible from Updater 1.0.3 through 1.0.10. After configuring
media output, remain on Updater 1.0.11 or newer; older releases do not understand
the added installed-profile field. Configuration/publication acceptance on a
production host is separate from source/CI and release publication.
