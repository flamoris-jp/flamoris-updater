# FLAMORIS Updater 1.0.0

First source implementation of the portable Update Core and FLAMORIS wrapper, dedicated operator Web, CLI, authenticated MCP, durable host execution, verified artifacts and protected recovery/self-update.

Applications own migrations, validators, writer fencing and isolated backup restoration. Initial installation and entry-version transitions are separately provisioned application work. Normal adapters cannot update coordinator/executor/recovery-controller roles. Unknown effects retain persistent blockers and are never automatically replayed.

Routine coordinator self-update requires idle mutations, a preinstalled stable recovery controller, current trusted previous/candidate releases, journal/control format v1, maintenance-only validation and acknowledged monotonic epochs on every managed host. Rollback preserves current identities, sessions, grants, revocations, catalogs and operation tombstones.

Release signing keys, catalog publication and real-host adoption are separate operator tasks. This source change does not publish a release or certify deployed applications.
