# FLAMORIS Updater v1.0.0

初回導入から各アプリのインストール・更新までを、独立したWeb・MCP・CLIで管理する初版です。
Linux amd64／arm64向けの依存ライブラリ入りバンドルを配布します。導入前に添付の
`SHA256SUMS`と`INSTALL-v1.0.0.md`を確認してください。Python 3.12とsystemdが必要です。

## Features

- Bootstrap creates the dedicated Web account, configuration, local root manager
  and independently pinned supervisor. No running FLAMORIS application is needed.
- Select applications individually through Web, MCP or CLI. Initial installation
  provisions executables/settings and waits for application setup and verification.
- Explicitly compatible updates keep configuration/data and verify health/runtime.
  Successful app updates retain current plus one previous executable generation.
- The supervisor updates Updater Web/manager from compatible indexed bundles,
  preserving authentication and history. It keeps its original installation.
- Persistent, scoped MCP keys support reconnecting after update downtime; Web
  operators can rotate/revoke them. Read-only keys cannot execute updates.
- Secret-free effect timelines and recorded current/candidate/previous layouts
  help AI prepare recovery procedures and installation documentation.
- Failed or interrupted effects retain evidence/blockers without automatic replay,
  rollback or data restoration. When Updater is down, recovery needs an independent
  administrator channel and human intervention.

## Distribution

Choose `flamoris-updater-1.0.0-linux-amd64.tar.gz` or
`flamoris-updater-1.0.0-linux-arm64.tar.gz`. Each includes runtime dependencies,
console launchers, an indexed file manifest and compatibility metadata. The
release also includes wheel/source distributions, the standalone Core SDK,
strict schemas, per-platform bundle metadata and SHA-256 checksums.

The initial-install distribution uses trusted GitHub HTTPS delivery and verified
checksums/indexes. It is not a signed advanced Core catalog. The separate protected
signing workflow remains available for that explicit integration.

## Supported boundary

Binaries are built and exercised on Ubuntu 24.04 for Linux amd64/arm64, with
Python 3.12. Installation requires systemd and administrator privileges. Automated
CI covers actual bundle staging/entrypoints, protected journals, Web/MCP authority,
new PostgreSQL database initialization and a disposable Generation Docker install.
Real host service replacement and external MCP clients are not certified by CI.

PostgreSQL, Docker, proxy/tunnel access, external AI runtimes/models and application
release catalogs are separate prerequisites/work. Existing unmanaged deployments
cannot be adopted. Generation Controller is embedded in Generation's package.
Compatible simple updates do not migrate DB schemas. No DB/system backup, data
restore, automatic recovery or scheduled auto-update feature is included.

This release provides Updater itself. Application distribution files and their
HTTPS installation catalog are prepared separately before selecting apps in Web.
