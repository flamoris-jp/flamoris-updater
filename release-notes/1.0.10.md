# FLAMORIS Updater 1.0.10

Fix managed Docker updates rejecting changed embedded component versions as retained runtime settings. Catalog-declared components are executable artifact metadata and can change with the release; the candidate image must still match them exactly. Mounts, environment file, ports, security, directories and other runtime bindings remain pinned, and operator configuration bytes remain preserved.

Legacy catalogs without components can update to an explicitly declared compatible release. Regression tests cover legacy/declared predecessors and refusal of mount changes. No application image, data schema, settings or GPU runtime is changed by this release. Self-update is compatible from 1.0.3 through 1.0.9.
