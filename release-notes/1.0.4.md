# FLAMORIS Updater v1.0.4

各アプリのリポジトリが配布物を管理し、Updaterの同じ画面から個別にインストール・更新する構成です。

- 複数カタログを登録できます。一つの配布元の確認が失敗しても、他の配布元の確認は継続します。
- Updater独自の管理者作成・セットアップコード・ログイン・セッション・CLI/MCPキーを削除しました。アクセスできる利用者は同じ更新操作を実行できます。
- Updater内の他アプリの一括ビルド・集中配布処理を削除しました。アプリの認証、OSの実行権限分離、ダイジェスト検証は別です。
- このReleaseの `catalog.json` は両CPU向けのUpdater本体を参照し、1.0.3からの自己更新を宣言します。カタログは検証済みの配布物から生成され、SHA256SUMSにも含まれます。
- 設定・データ・管理履歴と旧単一カタログ登録を引き継ぎます。DB・制御記録のスキーマ変更はありません。元のsupervisor配置は維持します。

1.0.3では既存画面でこのReleaseのカタログを登録してから自己更新します。公開済み1.0.3の配布物は変更しません。更新前に進行中Jobと実際の版・supervisorの配置を確認してください。

Linux/systemd・Python 3.12、amd64/arm64対応。各アプリの配布準備と実機でのインストール・設定・動作確認は、それぞれのリポジトリと運用手順に従います。CI成功は実機反映の証明ではありません。
