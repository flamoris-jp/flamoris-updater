# FLAMORIS Updater v1.0.1

`/updater`などのサブパスでWeb・API・MCPを公開できるようになりました。
初回導入では公開ドメインを`--public-origin`、パスを`--base-path`で指定します。
既存のルート直下の公開方法も引き続き利用できます。

- HTML, assets, browser API calls, authenticated MCP and CLI endpoint URLs share
  the configured prefix. `/updater` redirects relatively to `/updater/`.
- Exact Host/Origin, session/CSRF protection and bearer authority remain enforced.
  Forwarded-prefix headers cannot alter routes. Only configured prefixed routes
  are exposed; nginx must preserve the path and public Host when forwarding.
- The pinned self-update supervisor checks the prefixed health endpoint and
  recorded MCP placement includes the prefix. Existing setup configuration uses
  an empty default prefix; no database/journal schema migration is required.
- Linux amd64/arm64 bundles, wheels/source, Core SDK 1.0.0, schemas, installation
  instructions and SHA-256 sums are included. Python 3.12/systemd are required.

This release changes public routing only. It does not provision nginx, DNS, TLS,
application artifacts/catalogs or remote clients. Web/manager remain loopback
services. A proxy on a separate host needs an independently configured secure
relay to the target host's loopback listener. Real-host acceptance remains
separate from automated CI. Initial distribution is trusted GitHub HTTPS with
checksums/indexes, not a signed advanced Core catalog. Keep the original pinned
supervisor installation and preserve evidence if effects fail; no automatic
recovery, backup/restore or DB migration is added.
