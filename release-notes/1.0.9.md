# FLAMORIS Updater 1.0.9

Docker catalogs can declare embedded component versions, allowing Generation 1.0.3 with Controller 1.0.1 to install with exact metadata verification. Legacy Generation catalogs still require Controller 1.0.0. Existing artifact, image, release and platform validation remains in place.

Update Updater first, then install the new Generation catalog. Preserve existing settings, data and Jobs; no bootstrap rerun or model download is required by this change. This release does not change catalog display, job-history UI or input help.
