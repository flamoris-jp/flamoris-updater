# FLAMORIS Updater 1.0.16

Adds seven typed MCP, JSON HTTP and CLI tools for installation-support file transfers. Upload bounded chunks with SHA-256 verification, resume the identical pending chunk after an interrupted request, seal the complete file and read verified chunks. Explicit release removes only the staged copy and preserves its immutable receipt.

Files remain in the manager-owned `installation-transfers` root, below its configured state directory. Callers supply a transfer UUID and filename metadata, never a filesystem path. Private modes, no-follow descriptor access, link/special-file rejection and reservation/free-space limits confine the storage. Limits are 128 KiB per chunk, 1 GiB per file, and 4 GiB / 128 outstanding files.

Staged bytes are not executed, extracted, installed, copied to application configuration or adopted as release sources. Normal reviewed catalog/recipe installation remains separate. Existing endpoint access applies to all transfers; there is no per-user isolation or new authentication. Production assets belong to their owning application or a separate file service.

Self-update compatibility: 1.0.3 through 1.0.15. Existing v1 journals, the pinned bootstrap supervisor, application profiles and persistent data remain compatible; no schema or bootstrap change is required. Source/CI, publication and real-host acceptance are separate. See `docs/FILE_TRANSFERS.md` for the transfer and retry contract.
