# FLAMORIS Updater 1.0.12

Adds a persistent shared ComfyUI input-directory setting for managed Generation images with Controller 1.0.3 or newer. Reuses durable configuration Jobs, idle checks and fixed Docker bindings. Compatible application updates preserve the operator choice together with existing YuE2 output placement. Runtime.env, models, permissions and images are retained.

Self-update is compatible from 1.0.3 through 1.0.11. Once shared input is configured, keep Updater 1.0.12 or newer. Folder access, native ComfyUI readability and actual reference generation require host acceptance.
